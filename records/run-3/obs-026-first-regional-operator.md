1. **Первый конкретный оператор Bitbon существует.** Integration ICN (Казахстан). Это закрывает часть UNKNOWN «операторы Bitbon — реальные не найдены».

3. **Структура операторов двухуровневая** — региональные операторы + операторы сегментов сети.
4. **Событие — июнь 2025.** Совпадает по времени с исключением латвийского SIA (11.03.2025). Возможная реструктуризация: закрытие латвийской структуры → запуск казахстанской.

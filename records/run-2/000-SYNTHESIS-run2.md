## 2. Ключевые результаты

### 2.1. Техническая природа Bitbon (главный UNKNOWN Run 1 — закрыт)

**OBS-025.** GitHub-организация `simcord-llc` содержит публичный репозиторий **bitbon-system-blockchain**:
- README: «Official implementation of the Bitbon System Blockchain based on Ethereum codebase (go-ethereum)».
- Owner: **Simcord-LLC** (прямая ссылка на simcord.com).
- Структура — каталоги Geth.
- Каталог `quorum` + genesis с `initialSigners` = **permissioned-блокчейн** (Istanbul BFT).
- Активность: 2019-12-17 → 2022-05-06 (последний push — май 2022).
- Лицензия LGPL-3.0. 32 звезды, 4 форка.

**Расхождение:**
- OBS-013.4 (cooperation, ua): «технологію **публічних** розподілених реєстрів (блокчейн)».
- Фактически: permissioned-сеть, валидаторы фиксированы на старте.
- Технически это **не публичный блокчейн** в смысле открытого доступа.

### Об объекте

1. **Bitbon технически — permissioned-блокчейн на базе Geth.** Ключевое расхождение с публичным позиционированием.
2. **Инфраструктура simcord.com — зрелая, шире публичного портфеля.**

### О методе

1. **Технический контур — отдельный, эффективный класс источников.** WHOIS/DNS/CT/GitHub — работают пассивно и дают проверяемые факты.
2. **CT-логи — самый информативный технический канал.** 50 поддоменов за один запрос.
3. **GitHub API без авторизации — рабочий канал** для проверки заявлений о коде.
4. **Публичные реестры ИС (WIPO, USPTO, EUIPO) — закрыты.** Повторяет вывод Run 1.
5. **firmas.lv как альтернатива UR-порталу** — найден случайно, но полезен.
6. **Markdown-кодовые блоки в heredoc ломают команду.** Нужно использовать текст вместо фенсед-блоков в записях через heredoc.

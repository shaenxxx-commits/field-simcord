## ASSESS — оценка качества Run 1

### Что сработало

1. **Узкий FIELD.** D-20261016-01 (D4) ограничил источники официальным сайтом + Wayback + реестрами. Без этого объём был бы неуправляем.
2. **Правило D1 (факт публикации ≠ истинность).** Позволило отделить «компания заявила X» от «X истинно». Все 14 OBS построены по этому правилу.
3. **Wayback как обход SPA.** Сайт Simcord — React SPA, curl даёт пустой каркас. Wayback-снимки дали отрендеренный текст. Без этого OBSERVE был бы невозможен в пассивном режиме.
4. **YouControl как рабочий канал для ЕГРПОУ.** Первый SUPPORTED получен именно там (ACT-002).
5. **Google Patents как рабочий канал для патентов.** Второй SUPPORTED (ACT-004).
6. **Разделение ACT и OBS.** ACT — отдельные документы, не смешиваются с OBSERVE. Позволяет видеть, что подтверждено, а что нет.
7. **transitions.md заработал с первого перехода.** 10 записей UNKNOWN → SUPPORTED, I2 соблюдён без трения.

### Что не сработало / пробелы метода

1. **Агрегаторы ИС закрыты для пассивного режима.** WIPO Madrid Monitor, TMview, Укрпатент, USPTO, EUIPO — все SPA или API-key. ACT-003 = UNKNOWN без выхода. Границы D3 не позволили обойти.
2. **Bureau Veritas не имеет публичного онлайн-реестра.** ACT-001 = UNKNOWN. Сертификат не проверен.
3. **Google Patents не индексирует казахские и промобразцы.** KZ30184, KZ4296 = UNKNOWN. UA30256 = коллизия нумерации.
4. **Каскад «SPA/Cloudflare».** Clarity-project заблокирован Cloudflare. EUIPO/TMview — обрывы соединения. Один канал (YouControl) сработал из шести попыток. Это хрупко.
5. **Я преждевременно интерпретировал UA30256 как «расхождение».** Правильная версия — «возможная коллизия нумерации, требует проверки». Ошибка исправлена в ASSESS, но не в ACT-004.

### Что осталось непроверенным

- ~25 ТМ по номерам — ACT-003 UNKNOWN.
- KZ30184, KZ4296 — Google Patents 404.

8. **Представительство «Закарпаття»** в Мукачево — отдельный код ЕГРПОУ 44819099.
9. **24 судебных дела** — не исследованы.
10. **Расхождение позиционирования и портфеля.** Сайт: «блокчейн-компания». Портфель: 1 из 14 направлений — блокчейн, остальное IT/финансы/юридика.

1. **Wayback — рабочий обход SPA** для web-страниц.

## NEXT MOVE — куда идём

### Варианты

**A. Run 2 — News Flow.**
Раздел /news содержит ~200 публикаций за 2017–2024. Оттуда можно вытащить: заявленные события компании, партнёрства, лицензии в других странах, операторов Bitbon, региональные офисы, официальные позиции по ключевым темам. Это **богатый источник** для проверки расхождений.

**B. Run 2 — Технические артефакты.**

**D. Пауза.**
Зафиксировать Run 1 как завершённый, отчёт ведущему каркаса, решение о Run 2 — по возвращении.

### [ПРЕДПОЧТИТЕЛЬНО] A + B в тандеме

**Run 2: News + технический контур.** Обоснование:
- News даёт содержательные claim для проверки (партнёрства, лицензии, операторы).

1. WHOIS/DNS по трём доменам — дёшево, быстро.
2. Поиск публичного блокчейна Bitbon (explorer, транзакции).

## Ограничение выборки Run 3

**Что было:** Run 3 обработал 11 новостных публикаций из 100 уникальных слагов (sitemap ua+ru+en сайта simcord.com). 4 тематические группы: операторы, структура, приложения, регуляторика.

**Ограничение:** **все** обработанные статьи — с сайта Simcord. Источник зависимый. Он же — объект исследования. Это автопортрет компании.

**Что это даёт:**
- Репрезентативный срез самопозиционирования компании.
- Хронологию событий, как их видит сама Simcord.
- Терминологию и заявления компании.

**Чего это не даёт:**
- Независимой картины. Никакой внешней проверки в Run 3 не было.
- Критических сюжетов. Их нет в автопортрете по определению.
- Внешних оценок, регуляторных документов, судебных дел.

**Следствие:** Run 3 нельзя использовать как источник для выводов о соответствии заявленного реальному. Все 11 OBS размечены как зависимые (source_type: corporate), но в SYNTHESIS Run 3 это не выделено отдельным ограничением. CORRECTIONS восполняет этот пробел.

**Что рекомендуется:**
- В Run 4 (или отдельном ране) смещать баланс в сторону независимых источников: судебный реестр, реестры юрлиц, технические базы (CertiK, GitHub), внешние СМИ.
- Для внешних источников применять двухклассовую схему сохранения (см. docs/METHOD.md §8, дополнение от 2026-10-16).
- Не пытаться «переделать» Run 3. Автопортрет собран корректно и полезен как одна из сторон. Ограничение — не в качестве работы, а в природе источника.

### D-000000-00 — Initial setup field-simcord
- **Статус:** accepted
- **Дата:** 2026-10-15
- **Утверждающий:** Архитектор
- **Контекст:** Инициализация полевого проекта field-simcord по калиброванному каркасу KARCAS-DDA v1.1 (pilot), по образцу ENVOY.
- **Решение:** Развернуть структуру ~/field-simcord/ с минимальным ядром (README, CURRENT_STATE, DECISIONS, INVARIANTS) и библиотекой под полевую работу (00_ENTRY, docs/VISION, docs/METHOD, docs/KNOWLEDGE_STATES, meta/agent-rules, meta/handoff-protocol, meta/handoff-current, meta/transitions, meta/open-questions, PROVENANCE, records/, ARCHIVE/). ### D-20261016-01 — Решения по итогам Run 0 (внешние наблюдатели Luna / Kimi / Grok)
- **Статус:** accepted
- **Дата:** 2026-10-16
- **Утверждающий:** Архитектор
- **Контекст:** Run 0 — три внешних наблюдателя (Luna/GPT-6, Kimi, Grok) получили одно задание: прочитать публичный репозиторий, найти логические дыры, предложить Run 1. Синтез — records/000-LEAD-SYNTHESIS-run0.md. Синтез вынес шесть пунктов, требующих санкции Архитектора.
- **Решение:** Принять шесть пунктов:
  1. **D1.** Правило разметки: разделять «факт публикации» и «истинность содержания». Официальный источник подтверждает, что заявление сделано; он не подтверждает, что заявление истинно. Обязательно в Run 1.
  2. **D2.** Критерии завершения этапов Run 1 — по таблице из §9 LEAD SYNTHESIS (FIELD / OBSERVE / MAP / HYPOTHESIS / ACT / RESULT).
  3. **D3.** ACT-whitelist Run 1: только пассивные действия (открыть, сохранить, сопоставить, проверить архив, повторить поиск). Запрещено: обход авторизации, закрытые API, активное тестирование, любые контакты с объектом.
  4. **D4.** Узкий FIELD Run 1: официальный сайт Simcord, связанные ресурсы Bitbon, реестр ЕГРПОУ по коду 37657823, WHOIS/DNS по связанным доменам, Wayback по 2–3 контрольным датам.
  5. **D5.** Гипотеза Run 1 — H1 (методологическая): для части публичных утверждений удастся построить проверяемую цепочку от корпоративного заявления к независимому источнику. H1 не предполагает исхода и не даёт оценку истинности.
  6. **D6.** Два поля добавляются в минимальную полевую запись Run 1: `claim_id` (привязка наблюдения к утверждению) и `independence_status` (независимый / зависимый / неизвестно). Расширение минимальное, закрывает C2 и C6 синтеза.
- **Основание:** LEAD SYNTHESIS Run 0 (records/000-LEAD-SYNTHESIS-run0.md); консенсус трёх внешних наблюдателей (C1–C7); санкция Архитектора от 2026-10-16.
- **Последствия:** Run 1 проводится в узких границах, с пассивным ACT, с обязательной разметкой «факт публикации / истинность» и с двумя дополнительными полями фиксации. Это снижает риск системной ошибки, отмеченной всеми тремя наблюдателями.
- **Условие пересмотра:** Если Run 1 выявит недостаточность или избыточность любого из шести пунктов.
- **Связанные документы:** records/000-LEAD-SYNTHESIS-run0.md, records/001-RAW-external-1-luna.md, records/002-RAW-external-2-kimi.md, records/003-RAW-external-3-grok.md, docs/METHOD.md, docs/VISION.md.

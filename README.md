# field-simcord

Полевое исследование компании Simcord (ТОВ «СІМКОРД», код 37657823, Украина, продукт Bitbon).
Ведётся по каркасу KARCAS-DDA v1.1 (pilot), по образцу ENVOY.

## Вопрос исследования

Что представляет собой Simcord по публичным следам: структура, деятельность, соответствие заявленному позиционированию?

Ответ может быть любым. Предвзятость недопустима.

## Статус

Stage 0 — развёртывание поля. См. `CURRENT_STATE.md`.

## Минимальное ядро

- `README.md` — этот файл
- `CURRENT_STATE.md` — текущее состояние проекта
- `DECISIONS.md` — принятые решения и основания
- `INVARIANTS.md` — правила, которые нельзя нарушать (копия из каркаса)

## Библиотека (активные документы)

- `00_ENTRY.md` — обязательный порядок чтения
- `docs/VISION.md` — предмет, вопрос, границы
- `docs/METHOD.md` — полевой метод (заполнен под проект)
- `docs/KNOWLEDGE_STATES.md` — модель статусов знания
- `meta/agent-rules.md` — правила работы агента
- `meta/handoff-protocol.md` — протокол передачи контекста
- `meta/handoff-current.md` — текущий снимок передачи
- `meta/transitions.md` — переходы статусов знания
- `meta/open-questions.md` — открытые вопросы
- `PROVENANCE.md` — прослеживаемость утверждений
- `records/` — первичные записи
- `ARCHIVE/` — устаревшее

## Быстрый старт для агента

Читать в порядке `00_ENTRY.md`.

## Ограничения

Проект работает только с публичными следами Simcord. Внутренние материалы, частная переписка, персональные данные не собираются и не публикуются (см. `docs/VISION.md`, границы).

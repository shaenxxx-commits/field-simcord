# meta/architect-signals.md
Журнал сигналов Архитектора — наблюдений, версий, вопросов.
Режим: append-only.
Не является частью полевого исследования. Не подменяет records/, OQ, transitions.
Назначение: сохранить угол зрения Архитектора, не тормозя текущий Run.

Формат записи:

    <дата> | <тема> | <сигнал Архитектора> | <вопросы Архитектора> | <связь> | <статус>

Статусы:
    вне поля   — сигнал не о Simcord, может пригодиться в других проектах
    отложено   — релевантен Simcord, но не для текущего Run
    в работе   — релевантен текущему Run; ведущий учитывает при синтезе
    прижилось  — сигнал перерос во что-то большее (гипотеза, OQ, отдельный Run)

## Что это значит

**Пустое место в поле.** Компания заявляет себя как блокчейн-компания, публикует код Go-ноды, приглашает к аудиту — и независимого технического разбора кода ноды **нет**.

**Возможные объяснения (не выводы, гипотезы):**
1. Низкий интерес: 32 звезды на GitHub — проект незаметен в крипто-сообществе.
2. Репутационное восприятие: Simcord в крипто-сообществе ассоциируется с MLM/пирамидой (DOU, ForkLog). Инженеры не тратят время.
3. Сложность аудита: форк Geth, требует специализации.
4. Отсутствие публичного explorer/сети: технически проверять нечего, если нода работает в permissioned-режиме без публичных нод.
5. Возможно, аудит делался в частном порядке и не публиковался.

**Что это даёт для исследования:**

Это **само по себе значимо** для картины:
- заявление «блокчейн-компания» с открытым кодом, но без независимого подтверждения качества кода;
- единственная независимая техническая метрика (CertiK) — про ERC-20 токен ERBB, не про Bitbon-ноду. И там 45% (ниже среднего), без аудита.

**Оговорка.** Отсутствие аудита — не доказательство плохого кода. Это фиксация состояния публичного поля на дату наблюдения. Никаких квалификаций.

## Что из этого следует

1. **НДЦ блокчейн-решений — ключевая структура E4.** Simcord — технический партнёр НДЦ, не его часть. НДЦ подал Агробон на конкурс.
2. **Агробон — проект НДЦ, не Simcord.** Simcord разработал для него «провідні технічні рішення».
3. **Связь с США через GIST.** GIST (Global Innovation through Science and Technology) — инициатива при поддержке Госдепа США. Агробон — победитель в номинации «Агро- та харчові технології» (март 2023).
4. **Люксембург — точка выхода на EU.** ICT Spring 2023, украинский павильон (впервые), с участием посольства Украины в Бельгии.
5. **Партнёрские соглашения по Bitbon заключены на ICT Spring.** С кем именно — не указано. Число — «десятки встреч», не «сотни соглашений».
6. **Контекст для LUCC / Arnaud Lumet.** Он был соорганизатором украинского павильона; Simcord в нём участвовала. Связь через событие, не через партнёрство.
